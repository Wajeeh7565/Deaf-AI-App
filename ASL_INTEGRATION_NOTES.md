# ASL Integration Update

Added the supplied face-swapped ASL recordings to the YKF Accessibility Companion.

## Integrated ASL codes

1, 2, 3.1, 3.2.a, 3.5, 3.6, 3.8, 4.1, 4.5, 4.6, 5.1, 5.4, 5.5, 5.6.

Files are stored under `public/asl/` with normalized names such as `asl-5-4.mp4`.

The signing player now supports both ASL and LSQ media. ASL playback is wired into the active YKF journey screens: flight selection, baggage/check-in guidance, CATSA security steps, gate dashboard, gate change, delay, boarding, final call, cancellation, and passenger paging.

LSQ behavior remains unchanged.
