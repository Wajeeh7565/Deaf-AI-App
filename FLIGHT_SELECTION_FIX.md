# Flight selection mobile UI fix

Updated the flight-selection screen after real-phone testing.

Changes:
- Removed the small nested scroll box for flights; the page now scrolls naturally.
- Reduced the sign-language video area on this screen.
- Made mobile flight cards more compact so more flight information is visible.
- Removed the misleading preselected Calgary CTA on first entry; the passenger must tap a flight first.
- Added a sticky action area that does not shrink the flight list.
- Kept "My flight isn't listed" as a fallback.
